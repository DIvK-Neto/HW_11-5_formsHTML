# Используемые технологии и инструменты

Проект построен на современном стеке инструментов для разработки фронтенд-приложений.

## Основные технологии

- **JavaScript (ES6+)** – чистый JS без фреймворков.
- **HTML5, CSS3** – разметка и стили.

## Инструменты сборки и разработки

- **Webpack 5** – сборка модулей, минификация, горячая перезагрузка.
- **Babel** – транспиляция современного JS для поддержки старых браузеров.
- **ESLint** – проверка качества кода, соблюдение стиля.
- **Prettier** – автоматическое форматирование кода.

## Тестирование

- **Jest** – фреймворк для модульного тестирования.
- **JSDOM** – эмуляция браузерного окружения для модульных тестов.
- **Puppeteer** – управление браузером для e2e-тестов.

## CI/CD и автоматизация

- **GitHub Actions** – непрерывная интеграция и деплой.
- **Husky + lint-staged** – предварительная проверка кода перед коммитом.
- **semantic-release** – автоматическое создание релизов и тегов (опционально).

## Дополнительно

- **http-server** – простой статический сервер для e2e-тестов.
- **start-server-and-test** – утилита для запуска сервера и тестов в одном скрипте.
