# Установка и запуск проекта

## Требования

- Node.js версии 20 или выше (LTS)
- npm (поставляется с Node.js)

## Установка

1. Клонируйте репозиторий:

```bash
    git clone https://github.com/ваш-логин/HW_11-5_formsHTML.git
    cd HW_11-5_formsHTML
```

2. Установите зависимости:

```bash
    npm install
```

## Запуск в режиме разработки

```bash
    npm start
```

После запуска откройте браузер по адресу `http://localhost:8080`. Страница будет автоматически перезагружаться при изменениях в коде.

## Сборка для продакшна

```bash
    npm run build
```

Готовые файлы будут сохранены в папке `dist/`. Их можно развернуть на любом статическом хостинге.

## Использование виджета

В проекте уже есть пример двух кнопок с необходимыми атрибутами. Чтобы добавить собственный попап, создайте элемент с атрибутами `data-toggle="popover"`, `data-title` и `data-content`. Виджет автоматически инициализируется при загрузке страницы (см. `src/js/app.js`).
